04 / YOUR NEXT CHAPTER04 / فصلك القادم

A fresh perspective.وجهة نظر جديدة.
A useful next step.وخطوة تُحدث فرقًا.

You don’t need a big idea to make a difference. Fix a bug, clarify an instruction, or tell us what could work better.لا تحتاج إلى فكرة كبيرة كي تساهم. أصلح خطأ، أو وضّح تعليمات، أو أخبرنا بما يمكن تحسينه.

START SMALL. BUILD TOGETHER.بداية صغيرة. وأثر نتشاركه.

A little curiosity goes a long way.قليل من الفضول يفتح طريقًا.

You don’t need the whole answer. Start with one useful change, one clearer sentence, or one good question.لا تحتاج إلى كل الإجابات. ابدأ بتحسين مفيد، أو جملة أوضح، أو سؤال جيد.

Find your first stepاكتشف خطوتك الأولى
CODEالبرمجةImprove the code.طوّر الكود.

Start by understanding a project, then make one small improvement.افهم المشروع أولًا، ثم ابدأ بتحسين صغير وواضح.

  1. Explore the repository and read its README.استكشف المستودع واقرأ ملف README.
  2. Check the contribution guide before making changes.راجع دليل المساهمة قبل إجراء تغييرات.
  3. Open a focused pull request and explain your change.افتح Pull Request محددًا واشرح التغيير.
Read the contribution guideاقرأ دليل المساهمة
DOCUMENTATIONالتوثيقMake the docs clearer.اجعل التوثيق أوضح.

A clearer sentence can be as useful as a clever function.جملة أوضح قد تكون مفيدة بقدر دالة ذكية.

  1. Look for unclear instructions or missing examples.ابحث عن تعليمات غامضة أو أمثلة ناقصة.
  2. Check the Arabic and English experience.راجع التجربة بالعربية والإنجليزية.
  3. Suggest a change in an issue or a pull request.اقترح تحسينًا في Issue أو Pull Request.
Suggest an improvementاقترح تحسينًا
IDEAS & FEEDBACKالأفكار والملاحظاتShare an idea or a problem.شارك فكرة أو مشكلة.

Found a rough edge? Have an idea? Help us see what we’ve missed.وجدت مشكلة أو لديك فكرة؟ ساعدنا على رؤية ما فاتنا.

  1. Search existing issues to avoid duplicates.ابحث في القضايا الحالية لتجنب التكرار.
  2. Describe what happened and what you expected.اشرح ما حدث وما كنت تتوقع حدوثه.
  3. Add an example or steps to reproduce if you can.أضف مثالًا أو خطوات لتكرار المشكلة إن أمكن.
Explore the issuesاستكشف القضايا

Independent software. Shared possibilities.برمجيات نصنعها بعناية، ونطوّرها معًا.
