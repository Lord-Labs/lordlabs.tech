# Contributing to lordlabs.tech

Thanks for helping improve the LORD Labs website. Small fixes, clearer documentation, accessibility improvements, and Arabic/English corrections are welcome.

1. Check [existing issues](https://github.com/Lord-Labs/lordlabs.tech/issues) before opening a new one. For a large change, discuss the idea in an issue first.
2. Fork this repository and create a branch.
3. Edit files in `public/`. Keep both languages in sync (`index.html` and `app.js`). Preserve the supplied brand assets and palette.
4. Run `npm test` and `npm run build` with Node.js 22+. No dependency installation is needed.
5. Check desktop and mobile layouts, keyboard focus, Arabic RTL, and reduced motion. For a UI change, include screenshots with your pull request.
6. Open a pull request explaining the problem, the change, and what you verified.

For a bug, include the URL, browser, device/viewport size, expected behavior, actual behavior, and steps to reproduce. Do not include credentials, tokens, or private information.

Use respectful, constructive language. Source contributions are licensed under this repository’s MIT license; brand assets retain their separate ownership.

## بالعربي

مساهمتك مرحب بها: إصلاح بسيط، ترجمة أفضل، توثيق أو تحسين لإمكانية الوصول. افتح Issue لو التغيير كبير، ثم اعمل Fork وفرعًا جديدًا. حافظ على اللغتين والهوية، وشغّل الاختبارات والبناء، وراجع الموبايل واتجاه RTL قبل إرسال Pull Request.
